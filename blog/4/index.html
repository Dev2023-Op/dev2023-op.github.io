How i find unique names for my projects


Thesaurus


The first way I create names for my project is using thesaurus.com. If im trying to make a antivirus I will think of keywords.
A very obvious one being virus. I will then go over to thesaurus and type in virus. Thesaurus gives me illness my project name becomes Illness Antivirus


Word ladder


If my project is a python server(such as flask) that encrypts data. I can take the programming language or a service it uses and put it through the word ladder.
For example:

  • Python > snake > annaconda - my name is now Annaconda Encrypt
  • Flask > Drink > Water > Hydrogen aswell as encrypt > cipher- my name is now Hydrogen Cipher

Acronym


If i want to name my service Auto Scan Phishing And Malware Encounter i can take the forst letters of the words. That becomes ASPAME
